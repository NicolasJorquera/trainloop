# AccentPicker

Selector del color de acento en Configuración: 8 muestras predefinidas, sin selector libre.

- Rejilla de 4 × 2 botones reales de 72 px de alto, `radius-md`; la muestra usa el valor oscuro del acento (`accent-<nombre>`) y el nombre localizado debajo en `caption`.
- Seleccionado: anillo de 3 px en `ink` y un ícono ✓ en `phase-work-ink` sobre la muestra; `aria-pressed="true"`.
- Bajo la rejilla, una vista previa con la fase Trabajo (el acento) y Descanso, para ver el contraste antes de salir.
- Texto de ayuda: «Cambia el color de botones, barras y la fase de trabajo. Todos tienen el mismo contraste.»
- El cambio se aplica al instante en toda la app y se guarda en el teléfono; no cambia `danger`, `success` ni `warning`.
- Nombres: Orquídea / Orchid / Orquídea; Rosa / Pink / Rosa; Rojo / Red / Vermelho; Naranja / Orange / Laranja; Amarillo / Yellow / Amarelo; Lima / Lime / Lima; Azul / Blue / Azul; Violeta / Violet / Violeta.
