# BottomNav

Barra inferior con las cuatro pestañas: Inicio, Entrenar, Historial y Progreso.

- Alto 68 px, fondo `surface-1` (en oscuro, un tono sobre `bg`), sin sombra.
- Cada pestaña: ícono de trazo de 22 px y etiqueta `overline` reducida a 11 px, en mayúsculas.
- Activa: indicador superior de 3 px en `accent`, ícono y etiqueta en `ink`. Inactivas: `ink-muted`.
- Se oculta en modo sesión (temporizador, sesión de fuerza, resumen).
- Accesibilidad: `nav` con etiqueta localizada; la pestaña activa lleva `aria-current="page"`.
- Idiomas: INICIO / HOME / INÍCIO; ENTRENAR / TRAIN / TREINAR; HISTORIAL / HISTORY / HISTÓRICO; PROGRESO / PROGRESS / PROGRESSO.
